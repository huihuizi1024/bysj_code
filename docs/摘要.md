当前高校心理健康服务供需失衡，传统干预模式面临覆盖不足、病耻感阻碍等困境。本项目实现了一个基于大语言模型的大学生心理支持对话系统 MentalAlign。

系统采用前后端分离架构：后端基于 Spring Boot 3 与 MyBatis-Plus，含 12 个 RESTful 控制器与 19 个服务接口；前端基于 Vue 3 与 Element Plus，支持 SSE 流式对话、多模型切换及 ECharts 情绪可视化。AI 层支持 DeepSeek、OpenAI、Kimi 及本地模型，统一遵循 OpenAI 兼容 API 规范。

核心机制包括：（1）PRS 机制，以参与度（0.40）、情感效价（0.35）、唤醒度（0.25）为权重量化心理状态，驱动强支架/中度支持/反思性对话三级干预；（2）意图分类与角色调度，将输入重构为 11 种临床意图，映射至 ACT/CBT/DBT 疗法维度，驱动五类 AI 角色自适应切换；（3）Guardian 四层 OR 危机检测管道，依次涵盖 PHQ-9 语义层、BGE 向量语义层（阈值 0.55）、关系脉络门控层与关键词硬匹配层；（4）Reflector 输出审计层，检测自伤建议、医疗处方、歧视语言及 AI 伦理违规并安全替换。

系统采用 MentalAlign 评估框架（CSS/ARS）与 Google HEART 体系（满意度 0.30 / 参与度 0.15 / 接受度 0.15 / 留存率 0.20 / 任务成功率 0.20），危机检测召回率显著、疗效评分稳定，为扩大高校心理健康服务覆盖半径提供了可扩展技术路径。
